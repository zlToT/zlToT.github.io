## 第一步：判断改版类型

先问清楚用户意图：

> "你想要**大改版**（换配色/布局/结构）还是**小打磨**（加动效/质感/细节）？"

### 大改版模式

1. 先读 index.html，了解现有内容
2. 先问用户选**设计系统**：
   > "你想要哪种设计风格？**小清新**（浅色双色交替 + 波浪过渡）还是**南孚科技风**（深蓝主色 + 亮蓝点缀 + 光晕背景）？"
   >
3. 确认设计系统后，再在对应配色方案里选具体颜色
4. **生成独立预览文件**，不碰原文件
5. 用户迭代确认后，再合入 index.html

### 设计系统

#### 系统 A：小清新

- 全页浅色为主，仅末尾 section 用深底压轴
- 双色交替 section（奶杏→浅色→奶杏→浅色），形成清新节奏
- section 之间用 SVG 海浪曲线过渡
- Hero 左右斜切分屏 + 波浪装饰
- 卡片带渐变遮罩，柔和阴影

#### 系统 B：南孚科技风

- 深蓝 `#0A2B4E` 主色 + 亮蓝 `#3B82F6` 点缀
- 白色/浅灰 section 交替
- 全局蓝色光晕背景（radial-gradient + blur）
- Hero 左右布局 + 大数字统计块（南孚风核心）
- 渐变标题（navy→blue background-clip: text）
- 导航半透明 navy + backdrop-filter 模糊
- 卡片 hover 阴影带蓝色调
- 按钮圆角饱满、硬朗悬浮感

#### 系统 C：暗黑系

- 全页**深色为主**（近黑石墨/墨绿），无纯白背景，适合代码雨 / Matrix 背景效果
- 双色交替 section（深 → 更深），形成暗色节奏
- 全局暗色光晕背景（radial-gradient，深色底 + 荧光色微光晕）
- 卡片**深色玻璃**（半透明深底 + 荧光描边微光）+ hover 荧光阴影
- 文字浅灰白为主，点缀色用于高亮 / 渐变标题（浅色→荧光色）
- 导航半透明暗色 + backdrop-filter 模糊
- 保留南孚风核心：大数字统计块、渐变标题、光晕背景
- 移动端自动降级：动效 / 光晕简化，深色导航常驻

#### 系统 D：治愈系（当前默认）

- 背景：椭圆径向渐变 `radial-gradient(ellipse at 30% 40%, #E8F3EC, #D4E8DA)`
- 全局光晕：`body::before` 双绿光晕 `rgba(87,182,108,0.12)` / `rgba(125,207,166,0.1)`
- 玻璃卡片：`rgba(235,248,235,0.65)`（glass-base）+ 描边 `rgba(80,120,90,0.18)`（glass-edge）
- 主绿 `--green-accent #2F855A`：导航激活、tag 文字、小标题、按钮底
- 浅绿 `--green-light #57B68C`：hover 系、光晕、点缀
- 深字 `--text-dark #1A2E24` / 弱字 `--text-dim #406653`
- 标题渐变：`linear-gradient(135deg, #1E4A2F, #2F855A)`
- 大数字渐变：`linear-gradient(135deg, rgb(35,107,72), rgb(47,133,90))`
- 侧栏：浅绿玻璃 `rgba(225,242,225,0.7)` + 阴影 `rgba(40,70,50,0.15) 8px 0 25px -12px`
- 卡片 hover：背景 `rgba(47,133,90,0.12~0.15)` + 描边变 `#2F855A`；active 底 `#2F855A` + 白字
- 圆角偏大（参考站 card-radius 28px）、绿调阴影、半透明浅绿导航

### 小打磨模式

给出 4-5 个可选的视觉增强方向：


| 选项         | 效果                             | 改动量               |
| ------------ | -------------------------------- | -------------------- |
| 过渡光斑     | section 间雾状薄荷光晕，柔和过渡 | 少量 CSS + 几个 div  |
| 3D 卡片倾斜  | 卡片 hover 时微旋转 + 景深阴影   | 改 2 行 CSS          |
| 头像光环旋转 | 头像外围渐变色圆环缓慢旋转       | 加伪元素 + 动画      |
| 鼠标跟随光晕 | 页面跟随鼠标移动的柔光           | 少量 CSS + ~10 行 JS |
| 文字渐入动效 | 标题或标语逐个字淡入             | 少量 CSS + JS        |

用户选好后 → 生成预览 → 确认 → 合入。

## 核心原则

- **无论如何都不要在没有预览的情况下直接改原文件**
- 一次只改一个方向，让用户看清差异再继续
- 保持现有配色和字体风格，不做破坏性变更
- 移动端自动降级（动效在手机上隐藏或简化）
- 新增的视觉效果用纯 CSS 实现，不引入图片或三方库
- section 过渡区域是视觉优化的重点（用户的视觉注意力最集中在那里）

## 已知项目信息

- 项目：zlToT 个人作品集（Vue3 + Vite 工程，工程目录 `zlToT.github.io-site/`）
- 主页入口：`src/App.vue`（单页锚点滚动，组件化开发，非单文件 index.html）
- **当前设计系统：系统 D 治愈系（浅绿玻璃）**——背景 `#E8F3EC→#D4E8DA`、玻璃 `rgba(235,248,235,0.65)`、主绿 `#2F855A`、浅绿 `#57B68C`、文字 `#1A2E24`
- 全局背景：`radial-gradient(ellipse at 30% 40%, #E8F3EC, #D4E8DA)`
- 按钮：主绿底 `#2F855A` 渐变 + 白字（参考站 active/contact 按钮配色）；标题渐变 `#1E4A2F→#2F855A`
- 字体：系统字体栈（PingFang SC / Microsoft YaHei / Segoe UI）
- 布局：左侧导航（250px，头像 logo）+ 五个锚点板块（首页 / 技能 / 小游戏 / 有趣网站 / 联系方式），移动端顶部头像区+直排按钮（无汉堡）
- 已有效果：首页代码雨（canvas Matrix 风）、全屏 scroll-snap 翻页、大数字统计块、渐变标题、深色玻璃卡片、绿色光晕背景、技能板块折叠动画、小游戏独立页面
- 全局样式：`src/style.css`（CSS 变量 token 统一管理配色，改配色优先改这里；独立小游戏页 `public/games/*.html` 需单独替换颜色）
